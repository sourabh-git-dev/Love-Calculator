# 💖 Love Calculator – From Childhood Curiosity to Code  

## 📖 Story  
As a child, I always wondered how *“Love Calculators”* worked. They seemed magical — type two names and a percentage appears!  
Now, as a developer, I decided to build my own version and uncover the logic behind it.  

This project is not just about fun — it’s about *learning, debugging, and turning curiosity into code*.  
While building, I encountered several bugs and errors, but each one reminded me of the trial-and-error joy I felt back then.  

---

## 🚀 Features  
- Enter two names and get a love compatibility percentage  
- Simple and playful UI  
- Randomized results for fun  
- Responsive design
